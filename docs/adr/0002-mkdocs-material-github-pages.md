# 2. Documentation Engine and Hosting via MkDocs and GitHub Pages

Date: 2026-07-27

## Status

Accepted

## Context

Resource Flow is a domain-specific language (DSL) for process modeling and graph execution. Clear, searchable, and responsive documentation is required for language syntax, CLI usage, unit conversions, and visual execution plan exports.

The repository is hosted on GitHub (`ThomasKottenhahn/resource-flow`). We needed a hosting solution that integrates seamlessly with GitHub, requires minimal maintenance, and supports native rendering of Mermaid.js diagrams generated by the `rflow` CLI tool.

## Decision

1. **MkDocs + Material Theme**: Use `mkdocs` with the `mkdocs-material` theme for building static documentation from Markdown files stored in the `/docs` directory.
2. **Mermaid Diagram Support**: Enable PyMdown extensions (`pymdownx.superfences` with custom fence handler) to natively render Mermaid flowchart diagrams within documentation pages.
3. **GitHub Pages Deployment**: Automate building and deploying the site using GitHub Actions (`.github/workflows/docs.yml`), building on every push to the `main` branch.
4. **Structured Documentation Layout**: Organize documentation into logical pages (`index.md`, `getting-started.md`, `language-guide.md`, `cli-reference.md`, `examples.md`, `architecture.md`).

## Consequences

- Documentation remains co-located with source code in Git.
- Visual execution graphs exported as Mermaid code render directly on the web page.
- Zero server maintenance; deployment is automated via GitHub Actions on GitHub Pages.
